# 街コロ GitHub Pages v1.3.20

## 主な変更
- CPUロジックを `MACHIKORO_CPU_V2` へ更新
- CPU思考はホストブラウザ側で実行
- Workerへ送るのはCPUが決定した行動だけ
- CPU判断理由、全候補、評価点、点数内訳をIndexedDBへ保存
- 人間プレイヤーの正式に受理された行動も解析ログへ保存
- ゲーム終了時、サーバー用の圧縮版ログを1回だけWorkerへ送信
- タイトル画面に「CPU解析ログ」を追加
- サーバーJSON一括出力 / ローカル詳細JSON出力 / ログ削除に対応

## CPU v2で追加した主な判断材料
- 1個振り / 2個振りの期待値
- 出目確率
- 施設ごとの期待収入
- 赤施設による相手への圧力
- 牧場×チーズ工場などのコンボ
- 駅、港、ショッピングモール等との相性
- ランドマーク完成数と勝利までの距離
- 重要ランドマークへ向けた貯金価値
- BAN候補の「相手への損失 - 自分への損失」
- 電波塔の振り直し期待値
- 港+2前後の価値比較
- ビジネスセンター、清掃業、引っ越し屋等の対象評価
